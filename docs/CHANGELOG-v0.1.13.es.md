# Changelog · Compo v0.1.13

Versión orientada a publicación en repositorio público source-available y distribución como release beta.

## Cambios principales

- Preparados paquetes diferenciados para repositorio y release.
- Añadido icono de Compo en formatos SVG, PNG e ICO.
- Añadido instalador de acceso directo para Windows (`install-shortcut.bat` + `install-shortcut.ps1`).
- Añadido desinstalador simple del acceso directo (`uninstall-shortcut.bat`).
- Añadidos `NOTICE`, `SECURITY.md`, `CONTRIBUTING.md`, `.gitattributes` y plantillas básicas de issues para GitHub.
- Actualizado README para explicar publicación source-available y límites de licencia.
- Actualizada documentación de primer arranque con creación de acceso directo.
- Regenerados hashes SHA256.
