# Changelog · Compo v0.1.13

## Cambios principales

- Se mantiene el estilo visual de la aplicación local.
- Se añade una hoja CSS independiente para que la versión online/manual pueda adoptar una estética similar a Compo local.
- Se incorpora una página breve de primer arranque en `docs/PRIMER-ARRANQUE.es.md`.
- Se añade una pantalla interna de instrucciones de uso.
- Se añade una pantalla interna de licencia.
- La aplicación deja de ofrecer borrado de modelos locales de Ollama desde la interfaz.
- Se mejora la gestión de errores de Ollama con mensajes más accionables para conexión, timeout, modelo no encontrado, respuesta vacía y errores HTTP.
- Se sustituye la licencia MIT por una licencia beta restrictiva de uso, titularidad de Víctor Villapalos Pardiñas.

## Nota de distribución

Esta versión es adecuada para beta controlada. Para distribución estable se recomienda añadir pruebas de interfaz automatizadas y revisar jurídicamente la licencia si se prevé publicación amplia o explotación comercial.
