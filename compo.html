› Instrucciones de uso

Instrucciones de uso

Guía breve para trabajar con Compo local y Ollama.

Flujo recomendado

  1. Elige Prompt, Agente o Skill desde el menú superior.
  2. Escribe una necesidad en lenguaje natural: objetivo, destinatario, contexto y límites.
  3. Pulsa Generar. Si Ollama está activo, Compo usará el modelo local seleccionado; si no, generará una estructura de respaldo.
  4. Revisa el resultado. Usa Regenerar para una variante o Revisar para una auditoría crítica.
  5. Copia, descarga o exporta el proyecto. Al terminar, pulsa Apagar para cerrar el servidor local de Compo.

Ollama y modelos

Compo detecta los modelos instalados en Ollama, permite elegir el modelo activo y ofrece descargas recomendadas. Por seguridad operativa, Compo no borra modelos locales desde la interfaz.

Primer arranque

Para instalación y primer arranque, consulta la guía breve incluida en la carpeta docs. Abrir guía de primer arranque.

Criterios de uso seguro

  • No pegues datos personales o confidenciales salvo que el contexto local sea adecuado y tengas autorización.
  • Revisa manualmente prompts, agentes y skills antes de usarlos en producción.
  • Las skills generadas deben considerarse borradores operativos: comprueba activación, límites, ejemplos y guardrails.
  • Ollama es un servicio independiente: apagar Compo no apaga Ollama.
